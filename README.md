# Bloqueador de Aplicativos

Aplicativo desktop em Python que permite **bloquear a execução de aplicativos específicos por um tempo determinado**, monitorando processos em segundo plano e encerrando-os automaticamente.  
Uma ferramenta simples para ajudar no foco, produtividade e controle de uso de softwares.

---

##  Funcionalidades

- **Define um tempo de bloqueio** para um aplicativo.
-  **Monitoramento automático** de processos em segundo plano.
-  **Encerra o aplicativo** caso seja aberto durante o bloqueio.
-  Interface gráfica criada com **Tkinter**.
-  Uso da biblioteca **psutil** para detectar e controlar processos.
-  Funciona no Windows.

---

##  Tecnologias Utilizadas

- Python 3.x  
- Tkinter (interface gráfica)  
- Psutil (monitoramento de processos)
